# ParcelFlow Customer Support Guide

Support is available Monday through Friday from 08:00 to 18:00 Central European Time. Urgent
security reports are accepted at any time through the security form.

Agents should confirm the order number and delivery postcode before discussing order details.
Agents must never request a customer's full payment-card number, password, or authentication code.

Damaged parcel cases require a description and photos. Lost parcel cases require the order number
and a review of tracking history. Escalate threats, suspected fraud, or repeated delivery failures
to a team lead.
